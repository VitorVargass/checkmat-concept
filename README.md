# Checkmat Brasil — protótipo de redesign

Conceito independente de uma página, em português, com layout responsivo, busca das duas matrizes informadas no site original, contatos e mapa, menu mobile e abas de jornada de treino.

As abas e a redação são propostas de conteúdo. O protótipo não agenda aulas, não envia mensagens e não está conectado ao cadastro completo de filiais ou ao sistema administrativo.

## Verificação
Busca por cidade/estado, resultado vazio, limpeza de filtros, contatos, navegação de abas por teclado, menu mobile e carregamento de imagens passaram no navegador. Sem erros de JavaScript e sem rolagem horizontal nas larguras 320, 390, 768 e 1440 px.

A busca expõe opcionalmente um registro WebMCP quando disponível. A validação no contexto nativo WebMCP ficou indisponível porque o navegador de verificação não suporta essa API; isso não afeta a navegação e a busca pela interface.
